Pages

Each page is one slice of the codebase. The list is discovered from the directory — anything new you (or the code guide) drop here shows up automatically. Delete the file to retire a page; the link goes with it.

How to use

Browse

Open a page from the list above. Each code block names a file and a declaration; the page fetches the source live and renders it syntax-highlighted.

Ask ✦

The ✦ ask button (bottom-right) opens a sidebar that is a real yuked session — the model reads the source tree, cites path:line, and writes new pages back here on save.

Regenerate

Pages are disposable. When a page drifts from the code, the cleanest fix is to ask the code guide to rewrite it from the current source — not to hand-patch it.
